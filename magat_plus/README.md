# MAGAT+

Based on the work by [Li et. al.](https://arxiv.org/abs/2011.13219) that presents MAGAT,
we present here MAGAT+.

## Structure Overview
This directory contains the implementation of the MAGAT+ model, code to generate the dataset
for the model and code to train the model. The CNN encoding definition and parts of
the model definition in `magat_plus/magat/agents.py` are taken from the implementation of
[MAGAT](https://github.com/proroklab/magat_pathplanning). We include the LICENSE
from the forementioned repository at `magat_plus/magat/LICENSE`. 

```plaintext
├── magat_plus
|   ├── additional_data
|   |      Cost-to-go matrix generation.
|   |
|   ├── magat
|   |   ├── model
|   |   |      GNN definitions for MAGAT+.
|   |   └── agents.py
|   |          Model definition, processing from the graph input to action outputs.
|   |
|   ├── collision_shielding.py
|   |      Code to allow naive or PIBT collision shielding for the model.
|   ├── convert_to_imitation_dataset.py
|   |      Converts raw expert prediction to graph based format.
|   ├── dataset_loading.py
|   ├── generate_additional_data.py
|   |      Generates any additional input dataset, like cost-to-go matrix, greedy actions, history.
|   ├── generate_pos.py
|   |      Code to generate the agent position dataset.
|   ├── imitation_dataset_pyg.py
|   |      Dataset definition for the torch geometric graphs.
|   ├── loss.py
|   ├── lr_scheduler.py
|   ├── README.md
|   ├── run_expert.py
|   |      Code to generate the raw expert predictions.
|   ├── run_model.py
|   |      Code to run a MAGAT+ model on POGEMA environment.
|   ├── runtime_data_generation.py
|   |      Unifying code to take environment observations and produce graph data.
|   ├── train_imitation_learning_pyg.py
|   |      Trains MAGAT+ models on relevant datasets.
|   ├── training_args.py
|   └── utils.py
└── test_imitation_learning_pyg.py
       Code to test the trained model.
```

## Usage

### Dataset Generation
The dataset is generated by first running the expert on certain map distribution. Below we show the command
to generate the dataset used by the pre-trained MAGAT+ model in the paper. Please update `/path/to/dataset`
with the appropriate path.

```sh
python -m magat_plus.run_expert --dataset_dir /path/to/dataset --obs_radius 5 --num_samples 30000 --save_termination_state --expert_algorithm LaCAM --map_type mixed --obstacle_density_max 0.7 --ensure_grid_config_is_generatable
```

This can then we converted to an imitation learning dataset.

```sh
python -m magat_plus.convert_to_imitation_dataset --dataset_dir /path/to/dataset --obs_radius 5 --num_samples 30000 --save_termination_state --expert_algorithm LaCAM --map_type mixed --obstacle_density_max 0.7 --ensure_grid_config_is_generatable --use_lists
```

Normalized cost-to-go features can be generated for the dataset as below.

```sh
python -m magat_plus.generate_additional_data --dataset_dir /path/to/dataset --obs_radius 5 --num_samples 30000 --save_termination_state --expert_algorithm LaCAM --add_data_cost_to_go --normalize_cost_to_go --map_type mixed --obstacle_density_max 0.7 --ensure_grid_config_is_generatable --clamp_cost_to_go 1.0
```

Finally, as MAGAT+ uses relative position-based edge features, we also generate the positional data.

```sh
python -m magat_plus.generate_pos --dataset_dir /path/to/dataset --obs_radius 5 --num_samples 30000 --save_termination_state --expert_algorithm LaCAM --map_type mixed --obstacle_density_max 0.7 --ensure_grid_config_is_generatable --use_edge_attr --use_lists
```

### Training
The MAGAT+ model can be trained on the previously defined dataset, by appropriately replacing the `/path/to/dataset`
and `/path/to/checkpoints` values below.

```sh
python -m magat_plus.train_imitation_learning_pyg --dataset_dir /path/to/dataset --obs_radius 5 --num_samples 30000 --save_termination_state --expert_algorithm LaCAM --add_data_cost_to_go --normalize_cost_to_go --map_type mixed --obstacle_density_max 0.7 --ensure_grid_config_is_generatable --clamp_cost_to_go 1.0 --use_lists --checkpoints_dir /path/to/checkpoints/magat_plus_pretrained --run_name magat_plus_pretrained --device -1 --run_online_expert --attention_mode MAGAT_multiplicative --model_residuals all --use_edge_attr --use_edge_attr_for_messages positions+manhattan --edge_attr_processor MLP --load_positions_separately --train_on_terminated_agents --recursive_oe --cnn_mode ResNetLarge_withMLP --collision_shielding naive --action_sampling probabilistic
```

### Fine-Tuning
The pre-trained MAGAT+ model can then be finetuned on a single map. Below we show the commands to finetune on a dense warehouse map, which
involves first generating and saving the map.

```sh
python save_maps.py --obs_radius 5 --map_type mixed --map_types warehouse=1.0 --num_agents 128+128 --wall_width_min 8 --wall_width_max 8 --vertical_gap 1 --num_wall_rows_min 5 --num_wall_rows_max 5 --num_wall_cols_min 2 --num_wall_cols_max 2 --side_pad 3 --max_episode_steps 512 --min_dist 10 --map_dir /path/to/dataset/maps/dense_warehouse --num_maps 1
```

The dataset generation follows the same structure as for pre-training.

```sh
python -m magat_plus.run_expert --dataset_dir /path/to/dataset --num_samples 1000 --expert_algorithm LaCAM-30 --obs_radius 5 --map_type mixed --map_types pregen=1.0 --num_agents 32+48+64+80 --max_episode_steps 512 --min_dist 10 --map_dir /path/to/dataset/maps/dense_warehouse --num_maps 1 --maps_name dense_warehouse --save_termination_state

python -m magat_plus.convert_to_imitation_dataset --dataset_dir /path/to/dataset --num_samples 1000 --expert_algorithm LaCAM-30 --obs_radius 5 --map_type mixed --map_types pregen=1.0 --num_agents 32+48+64+80 --max_episode_steps 512 --min_dist 10 --map_dir /path/to/dataset/maps/dense_warehouse --num_maps 1 --maps_name dense_warehouse --save_termination_state --use_lists

python -m magat_plus.generate_additional_data --dataset_dir /path/to/dataset --num_samples 1000 --expert_algorithm LaCAM-30 --obs_radius 5 --map_type mixed --map_types pregen=1.0 --num_agents 32+48+64+80 --max_episode_steps 512 --min_dist 10 --map_dir /path/to/dataset/maps/dense_warehouse --num_maps 1 --maps_name dense_warehouse --save_termination_state --add_data_cost_to_go --normalize_cost_to_go

python -m magat_plus.generate_pos --dataset_dir /path/to/dataset --num_samples 1000 --expert_algorithm LaCAM-30 --obs_radius 5 --map_type mixed --map_types pregen=1.0 --num_agents 32+48+64+80 --max_episode_steps 512 --min_dist 10 --map_dir /path/to/dataset/maps/dense_warehouse --num_maps 1 --maps_name dense_warehouse --save_termination_state --use_lists --use_edge_attr
```

Finally, we finetune our pre-trained model on this dataset by providing the path to the pre-trained weights. For the below example, we take
weights from epoch 195 (zero-indexed), as that was getting better validation scores than the last model.

```sh
python -m magat_plus.train_imitation_learning_pyg --dataset_dir /path/to/dataset --num_samples 1000 --expert_algorithm LaCAM-30 --obs_radius 5 --map_type mixed --map_types pregen=1.0 --num_agents 32+48+64+80 --max_episode_steps 512 --min_dist 10 --map_dir /path/to/dataset/maps/dense_warehouse --num_maps 1 --maps_name dense_warehouse --save_termination_state --add_data_cost_to_go --normalize_cost_to_go --use_lists --checkpoints_dir /path/to/checkpoints/magat_plus_dense_warehouse_finetuned --run_name magat_plus_dense_warehouse_finetuned --device -1 --run_online_expert --num_epochs 52 --attention_mode MAGAT_multiplicative --model_residuals all --use_edge_attr --use_edge_attr_for_messages positions+manhattan --edge_attr_processor MLP --load_positions_separately --train_on_terminated_agents --recursive_oe --cnn_mode ResNetLarge_withMLP --collision_shielding naive --action_sampling probabilistic --pretrain_weights_path /path/to/checkpoints/magat_plus_pretrained/epoch_195.pt
```

### Compiling
We note below the command for JIT compiling the finetuned model, using the last epoch weights, i.e. epoch 51.
We found that using the optional `torch_geometric` libraries, like `torch-scatter`, `torch-sparse` and `pyg-lib`,
led to errors for the compiled models, and hence, we disabling them for the JIT compilation.

```sh
python -m magat_plus.jit --dataset_dir /path/to/dataset --num_samples 1000 --expert_algorithm LaCAM-30 --obs_radius 5 --map_type mixed --map_types pregen=1.0 --num_agents 32+48+64+80 --max_episode_steps 512 --map_dir /path/to/dataset/maps/dense_warehouse --num_maps 1 --maps_name dense_warehouse --save_termination_state --add_data_cost_to_go --normalize_cost_to_go --use_lists --checkpoints_dir /path/to/checkpoints/magat_plus_dense_warehouse_finetuned --run_name magat_plus_dense_warehouse_finetuned --device -1 --run_online_expert --num_epochs 52 --attention_mode MAGAT_multiplicative --model_residuals all --use_edge_attr --use_edge_attr_for_messages positions+manhattan --edge_attr_processor MLP --load_positions_separately --train_on_terminated_agents --recursive_oe --cnn_mode ResNetLarge_withMLP --collision_shielding naive --action_sampling probabilistic --pretrain_weights_path /path/to/checkpoints/magat_plus_pretrained/epoch_195.pt --test_name try --subsample_n 5 --model_epoch_num 51 --jit_model_storepath /path/to/checkpoints/compiled/magat_plus_dense_warehouse_finetuned_epoch_51.pt --test_obs_radius 5 --test_num_samples 30000 --test_map_type mixed --test_map_types random=1.0 --test_num_agents 400+400 --test_obstacle_density_min 0.02 --test_obstacle_density_max 0.02 --test_ensure_grid_config_is_generatable --test_max_episode_steps 256 --test_map_w_min 32 --test_map_w_max 32
```
